# Chronicles Hub Frontend

Modern React + TypeScript + Vite frontend for Chronicles of Darkness character management.

## Implemented Core Features

- Login/register flow backed by API auth endpoints.
- Testing bypass button on auth screen (enabled in dev; can also be enabled with `VITE_ENABLE_BYPASS_LOGIN=true`).
- Character dashboard with search, sort, and quick card access.
- Six-step character creation wizard with point-budget validation.
- Character sheet with edit/read modes, health track cycling, and XP/Beat handling.
- Chronicle log/notes area with local persistence.
- Dark Gothic and Light Parchment themes.

## Commands

- `npm install`
- `npm run dev`
- `npm run check`
- `npm run build`
